# dropbear labs

The field-notes site at `dropbearlabs.io`. It is a small Jekyll site published
from GitHub Pages.

## content

Posts live in `_posts/` and use the shared `post` layout. New posts should
include a short `description`, a lowercase `title`, an `eyebrow` using the
`//` house style, and an explicit `permalink`.

The current content families are:

- `field notes` for measured work and active experiments;
- `essays` for arguments and conference reflections;
- `methods` for practical technical notes;
- `archive` for selected older writing.

## local build

```shell
bundle install
bundle exec jekyll serve
```

Then open `http://127.0.0.1:4000`.

## design

Dropbear and Slobberdog share behaviour rather than a compulsory palette:
lowercase labels, JetBrains Mono, `//` separators, quiet operational copy,
grain, scanlines and sparse borders. Dropbear retains the navy, pink and cyan
of its existing mark.
